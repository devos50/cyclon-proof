# Sampling from even-permutation-invariant recurrent classes

Conditional research reduction, 16 November 2026. This is an alternative to proving a unique full-state stationary regime. It does **not** establish class invariance for CYCLON, or arbitrary-shuffle-length convergence.

## Hypotheses

Fix the adopted iid-event protected/MIN chain with `n >= 5` and allowed `1 <= L <= c <= n-1`. Use the established general finite-reset consequences:

1. There are finitely many closed communicating classes, each positive recurrent.
2. Starting at any allowed state, the chain eventually enters one of these classes almost surely.
3. Every state is a weakly connected finite-integer-age overlay.

The state space is countable. Each closed class has a finite period and its usual cyclic decomposition. The event transition kernel is equivariant under peer relabelling.

The **unproved additional hypothesis** is:

> Every individual closed communicating class is invariant as a set under the alternating group `A_n` of even peer relabellings.

Equivariance alone only says that relabelling *permutes* the closed classes. It does not imply this hypothesis.

## Claim for one returned peer

Under these hypotheses, for every initial state and observer `i`, the deterministic-event-time one-ID sample conditional on availability converges to uniform on `V \ {i}`. Moreover,

`liminf_t Pr(C_i(t) is nonempty) >= ceil((n-1)/c)/n > 0`.

Full-state convergence need not hold: different classes can retain different stationary laws, and periodic availability can persist.

## General sample sizes

For every `b <= min(c, floor(n/2))`, the same conditional-uniform conclusion holds with no additional availability hypothesis. In particular, this covers all allowed request sizes in the sparse-capacity range `c <= floor(n/2)`.

For larger `b <= c`, the conclusion holds if every closed class contains at least one state having at least `b` entries at some peer. Symmetry and the occupancy-propagation argument below then establish positive availability at every observer in every cyclic phase. This extra large-`b` class-existence condition is **not established here**.

The observation rule is important: choose an unordered `b`-subset uniformly from the cache, then order it uniformly. The conditional conclusion is uniform on all ordered distinct `b`-tuples.

## Proof

### 1. Even relabellings fix each cyclic phase

Let `C` be a closed class of period `d`, with cyclic subclasses `C_0,...,C_(d-1)`. A relabelling `g` preserving `C` commutes with the transition kernel and therefore permutes this cyclic decomposition. Since it preserves successor phases, the induced permutation is a shift `r -> r + k(g) mod d`. Composition makes `k` a homomorphism from `A_n` to the abelian group `Z/dZ`.

This homomorphism is trivial. The group `A_n` is generated by three-cycles. When `n >= 5`, each three-cycle is conjugate to its inverse by an even permutation: exchange two of its moved labels and also exchange two labels outside its support. In an abelian image the three-cycle and its inverse have the same image, so that image has order dividing two. It also has order dividing three. It is therefore the identity. Consequently every `C_r` is itself `A_n`-invariant.

This handles periodicity rather than silently assuming aperiodicity.

### 2. Each phase stationary law has uniform conditional samples

The `d`-step chain restricted to `C_r` is irreducible, aperiodic and positive recurrent. Let its unique stationary law be `nu_r`. Equivariance and phase invariance imply `g_* nu_r = nu_r` for every `g in A_n`, by uniqueness.

The subgroup fixing observer `i` is `A_(n-1)`. It acts transitively on the unordered `b`-subsets of the other labels for every `b`. To see this, first map one subset to another by an arbitrary permutation; if that permutation is odd, change its parity using a transposition wholly inside the target subset or wholly inside its complement. With `n-1 >= 4`, at least one of those two blocks has size at least two whenever a correction is needed. The empty/full subset cases are immediate.

Availability is invariant under this subgroup. Hence, conditional on availability under `nu_r`, all unordered sample subsets have equal probabilities. Independent uniform ordering then gives uniformity on ordered tuples. There is no restriction to small `b` from the ordered-tuple transitivity degree of the alternating group, because the observation itself randomizes order.

Write `alpha_r` for availability under `nu_r`. The non-bottom output subprobability law is exactly `alpha_r U_b`, where `U_b` denotes uniform ordered sampling.

### 3. One-ID availability is uniformly positive in every phase

A weakly connected directed overlay has at least `n-1` arcs. A nonempty row has at most `c` arcs, so at least `ceil((n-1)/c)` rows are nonempty in every state. Since `nu_r` is invariant under `A_n`, which is transitive on peers, all peers have the same nonempty probability. Thus

`alpha_r >= ceil((n-1)/c)/n`.

### 3a. Automatic availability up to the sparse-capacity threshold

For a closed class `C`, let `m` be the greatest cache size appearing at any peer in any state of `C`. This maximum exists and is attained, since sizes lie in the finite set `0,...,c`.

If `m<c`, no legal transition from a state in `C` can have an eviction at either endpoint. An eviction is required only when the resident-plus-new set overflows, and the corresponding endpoint finishes with size exactly `c`; that would exceed `m` in a state that must remain in the closed class.

Without evictions, the underlying undirected graph can only gain edges. The mandatory selected-partner removal does not lose an underlying edge: the responder receives and protects the initiator's fresh reverse descriptor. All other resident edges persist. Because states in `C` communicate, this monotone graph must be one fixed graph throughout `C`. Even-permutation invariance makes that graph invariant under `A_n`. This group is transitive on unordered pairs, so the graph is either empty or complete. Weak connectivity excludes the empty case.

A complete underlying graph requires at least `n(n-1)/2` directed descriptors. Since every row has size at most `m`, this gives `m >= ceil((n-1)/2) = floor(n/2)`. Consequently, in all cases,

`m >= min(c, floor(n/2))`.

Thus every class contains an available state for every `b` up to that bound. Even relabelling gives such a state at each chosen observer `i`.

Availability also propagates to each successive cyclic phase. From a state with `|C_i|>=b`, choose any initiator different from `i`. The cache at `i` is either unchanged, or is the passive responder cache. A passive merge never decreases its size: vacancies are filled first and any evictions are matched by new insertions. Therefore a positive-probability next-phase state also has `|C_i|>=b`. Repeating this argument covers every phase. This same argument proves the stated class-existence criterion for larger `b`.

The stationary law of an irreducible positive recurrent countable chain assigns positive mass to every state, so phase availability is positive. There are only finitely many classes and finitely many phases in each, hence these positive availabilities have a positive common minimum. No explicit numerical bound for `b>1` is claimed.

### 4. Deterministic-time convergence of samples

For an entrance state `y in C_r`, periodic-chain convergence gives

`|| P^t(y, .) - nu_(r+t mod d) ||_TV -> 0`.

Applying the observation kernel cannot increase total variation. Thus the non-bottom output law approaches a scalar multiple of `U_b`, with scalar the phase availability. Its actual availability approaches that same scalar.

Let `tau` be the almost-sure finite entrance time into the union of the closed classes. Condition on the countably many possibilities `(tau, X_tau)` and use bounded convergence. The probability of `tau > t` tends to zero. The full non-bottom output law differs by a vanishing signed mass from `A_t U_b`, where `A_t` is its actual availability. The lower bound on phase availability gives `liminf A_t > 0`. Dividing by `A_t` proves the conditional-uniform limit, even if `A_t` itself oscillates.

The finite-regime/reset result supplies the eventual-entry hypothesis: repeated returns to a finite set cannot remain forever among its transient states. Positive recurrence and finiteness of the class set are established separately by the cited reset theorem; they are not consequences of symmetry.

## What this changes, and what it does not

For the local sampling target, it may suffice to prove that a recurrent class is unchanged by even relabellings, rather than that all recurrent classes communicate through a universal zero anchor. For example, a finite-path witness connecting a recurrent-class representative to each generator's relabelled copy would suffice for class invariance.

No such witness is proved here. Neither permutation equivariance, finite regime count, numerical tests, nor stationary symmetry after averaging over relabellings establishes individual-class invariance. The existing full-convergence route remains stronger and may still be easier to complete.

## A second conditional route: fewer than n recurrent classes

If the number `R` of closed classes is strictly less than `n`, their permutation action automatically satisfies the even-class-invariance hypothesis. Indeed `A_n` is simple for `n >= 5`; a nontrivial homomorphism `A_n -> S_R` would be injective. This is impossible because `|A_n| = n!/2 > R!` for `R <= n-1`. Thus all even relabellings fix every class.

Consequently a one-ID sampling counterexample under the finite-regime hypotheses would require at least `n` recurrent classes. This is only a necessary condition: the existing finite-reset argument gives a much larger upper bound, not `R<n`. No small-regime-count estimate is established here.
